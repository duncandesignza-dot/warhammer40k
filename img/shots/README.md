# Homepage screenshots

Each feature on the homepage shows a drawing made from the app's own parts.
To show a real screenshot instead, add a WebP file here with one of these names:

| File | Feature |
|---|---|
| `colours.webp` | Colour schemes |
| `units.webp` | Unit tracker |
| `recipes.webp` | Paints and recipes |
| `import.webp` | List import |

About 1200 × 800 pixels works well. The image fills the frame and is cropped from the top left, so keep the important part there.
